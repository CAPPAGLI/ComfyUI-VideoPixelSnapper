Palette & Frame Editor

Компаньон для Video Pixel Snapper — редактирование палитры, ручная правка кадров, сравнение было/стало

Загрузи кадры, чтобы начать: перетащи PNG/JPG сюда,
используй «Загрузить кадры» или «Загрузить папку» справа.
Отдельно можно загрузить палитру (например, выход palette_preview из ноды) через «Загрузить палитру».

Кадры

—
zoom 8x
Колесо мыши — панорама в любую сторону, даже за пределы того, что было видно раньше. Ctrl/Cmd + колесо — зум под курсором. Инструмент Pan (или средняя кнопка мыши) — панорама перетаскиванием.

Палитра

Палитра пуста — загрузи её или извлеки из текущего кадра.
Клик по свотчу — выбрать цвет для рисования. Shift+клик — пометить как акцентный (только для тебя, на экспорт не влияет). Крестик при наведении — удалить неудачный/лишний полутон.

Инструмент

Paint — рисовать выбранным цветом по клику/протяжке (снаппится на пиксельную сетку кадра). Pick — навести, чтобы увидеть цвет под курсором (окошко выше) и есть ли он уже в палитре; клик — взять его. Pan — панорама перетаскиванием.

Сравнение было/стало

Исходный кадр — тот же кадр видео до обработки Pixel Snapper, для сравнения. Раздел «стало с новой палитрой» пересчитывается вживую по текущей палитре слева.
Правки кадра хранятся только в этой вкладке — экспортируй, когда закончишь.
